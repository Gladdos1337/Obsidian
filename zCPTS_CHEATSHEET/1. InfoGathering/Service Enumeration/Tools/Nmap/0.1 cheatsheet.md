## Standard Workflow

```
[ ] 1. Host discovery (if allowed)
[ ] 2. Fast full-port TCP scan to find open ports
[ ] 3. Targeted service/version scan on found ports
[ ] 4. Script scan (vuln/default) on found ports
[ ] 5. UDP scan on common ports
[ ] 6. Save output in all formats (-oA)
```

---

## Core Scans

|Goal|Command|
|---|---|
|Host discovery (ping sweep, no port scan)|`nmap -sn 10.10.10.0/24`|
|Fast scan of all 65535 TCP ports|`nmap -p- --min-rate=5000 -T4 -Pn <ip>`|
|Service/version detection on found ports|`nmap -sV -sC -p<ports> <ip>`|
|Full aggressive scan (OS, version, scripts, traceroute)|`nmap -A <ip>`|
|Default scripts + version detection|`nmap -sC -sV <ip>`|
|UDP scan (top ports — full UDP is painfully slow)|`nmap -sU --top-ports 100 <ip>`|
|Skip host discovery (target known to be up / ICMP blocked)|`nmap -Pn <ip>`|
|Scan through a SOCKS proxy (pivoting)|`proxychains nmap -sT -Pn -p<ports> <ip>`|

---
## Scan Type Flags

|Flag|Meaning|Needs root?|
|---|---|---|
|`-sS`|SYN scan (stealth, default if root)|Yes|
|`-sT`|TCP connect scan (full handshake)|No|
|`-sU`|UDP scan|Yes|
|`-sA`|ACK scan (firewall rule mapping)|Yes|
|`-sV`|Version detection|No|
|`-sC`|Default NSE scripts|No|
|`-sN`/`-sF`/`-sX`|Null/FIN/Xmas (firewall evasion, IDS-quiet)|Yes|

---

## Timing & Performance

|Flag|Meaning|
|---|---|
|`-T0` – `-T5`|Paranoid → Insane timing (T4 is common default for labs, T3 is nmap default)|
|`--min-rate=<n>`|Send packets no slower than n/sec — speeds up full-port scans a lot|
|`--max-retries=<n>`|Lower retries = faster but less reliable on lossy/pivoted links|
|`-n`|No DNS resolution (faster)|

## Output

|Flag|Meaning|
|---|---|
|`-oN file`|Normal output|
|`-oX file`|XML output|
|`-oG file`|Grepable output|
|`-oA basename`|All three formats at once — **use this by default**|

## NSE Scripts

|Command|Use|
|---|---|
|`nmap --script vuln <ip>`|Check for known vulnerabilities|
|`nmap --script default <ip>`|Same as `-sC`|
|`nmap --script smb-enum-shares,smb-enum-users -p445 <ip>`|SMB enumeration|
|`nmap --script http-enum -p80 <ip>`|Web dir/file enumeration|
|`nmap --script ldap-search --script-args ldap.base='dc=domain,dc=local' <ip>`|LDAP enum|
|`ls /usr/share/nmap/scripts/ \| grep <keyword>`|Find scripts locally|

## Firewall / IDS Evasion (situational, know they exist)

| Flag                | Meaning                                               |
| ------------------- | ----------------------------------------------------- |
| `-f`                | Fragment packets                                      |
| `-D RND:10`         | Decoy scan with 10 random IPs                         |
| `--source-port 53`  | Spoof source port (bypass naive port-based filtering) |
| `--data-length <n>` | Pad packets to avoid signature-based detection        |

## Practical CPTS Habits

- Always run a **full port TCP scan first** (`-p- --min-rate=5000`) — don't rely on top-1000 default, exam boxes love hiding services on high ports.
- Follow up the full scan with a **targeted `-sC -sV`** only on discovered open ports — faster and cleaner output.
- Don't forget **UDP** — SNMP (161), TFTP (69), and DNS (53) findings are common and easy to miss if you skip `-sU`.
- When pivoting, remember the `-sT -Pn` rule above or your scan will just hang/return nothing.
- Save everything with `-oA` — you will want to grep results later without rerunning scans.
